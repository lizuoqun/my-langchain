# 实时汇率查询技能

## 触发条件

用户询问「汇率」「多少钱人民币」「换算成 X 币」等与货币兑换相关的问题时使用本技能。

## 必须先获取实时数据

**不要凭记忆回答汇率**，汇率每天都在变。必须调用 `http_get` 工具请求下面的地址：

```
https://open.er-api.com/v6/latest/CNY
```

含义：以人民币（CNY）为基准，返回 1 元人民币能兑换多少各外币。

## 返回内容说明

响应是一个 JSON，关键字段：

- `result`：`"success"` 表示成功
- `base_code`：基准币种，这里是 `CNY`
- `time_last_update_utc`：汇率更新时间，回答时必须告诉用户
- `rates`：各币种汇率表，例如 `"USD": 0.14` 表示 1 元人民币 ≈ 0.14 美元

## 回答规则

1. 先调用 `http_get`，拿到 JSON 后再回答。
2. 从 `rates` 里取出用户问的币种代码对应数值。
3. 如果用户要换算具体金额，用该数值相乘，保留 2 位小数。
4. 回答中必须带上「数据更新时间」（取自 `time_last_update_utc`）。
5. 如果 `result` 不是 `success`，或 `rates` 里没有该币种，直接说明查询失败，不要编造数字。

## 回答示例

> 1 元人民币约可兑换 0.14 美元（数据更新时间：2026-11-11 00:02:31 UTC）。
> 如果你有 500 元人民币，约合 70.00 美元。
